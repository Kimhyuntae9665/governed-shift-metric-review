# Architecture diagram provenance

Browser requests the loopback Python API. Frozen MES/time JSON exports, expected scope and approved catalog feed exact CPU Fraction metrics after authorization, revision and completeness checks. Optional Ollama/Qwen proposes ONLY an approved metric enum from the request and finite catalog; no source values enter that model request. The CPU parses explicit shift selection and the human applies proposed selectors before calculate. SQLite stores receipts, reviews and audits. The model never calculates metrics.

PNG is the inline README asset; SVG is the editable, fully embedded source. Six compact cards use actual technology glyphs where available. JSON braces are a locally authored functional symbol. Browser contains the JavaScript glyph for the vanilla client. The undirected Ollama/Qwen link denotes runtime/model association; dashed arrows are optional requests and returned proposals, not parallel GPU workers. The solid Python/SQLite arrow denotes server-owned arithmetic receipt persistence and subsequent review/audit records.
